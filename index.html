A clip-launching DAW, open source and written in Rust.

Launch clips, arrange them, and render the result, with plug-ins kept in a sandbox so that one crashing plug-in never takes your project down.

Pre-alpha

Download the nightly Source on GitHub Discord Itch.io

What it does today

  • Session and arrangement views, with clips launched in time with the song.
  • Audio clips with real-time time-stretching, and MIDI through the built-in FM synth.
  • CLAP and VST3 plug-ins, each running in its own process.
  • A browser with a sample map that lays out sounds by how they sound.
  • Every action available from the command line and over MCP, for scripts and agents.

The roadmap lists what works and what comes next.

Download

The nightly is built from the latest code every night. It is a development build: expect rough edges, and keep backups of projects you care about.
