# suhina-daw.github.io

The website of [Suhina](https://github.com/suhina-daw/suhina-daw), served by GitHub Pages at
<https://suhina-daw.github.io>.

The site is plain HTML: edit `index.html` and push to `main`; GitHub Pages publishes it within a
minute or two. Download links point at the nightly release, whose file names never change.
